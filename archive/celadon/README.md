# Archived: celadon palette

An alternative to the live midnight-blue palette, kept for later.

| Role | Colour |
|---|---|
| Primary | Beige `#efe7da` |
| Secondary | Celadon `#a9bdb8` (between light blue and sage) |
| Buttons and links | Deep celadon `#4e6a67` |
| Accents | Terracotta `#b8603d`, Plum `#5c2b4b` |

`celadon-theme.css` holds the rules. The `.jpg` files compare it with midnight
(A = celadon, B = midnight) section by section.
